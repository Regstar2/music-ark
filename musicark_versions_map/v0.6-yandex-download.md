# v0.6-yandex-download

## Цель

Реализовать скачивание доступных треков из Яндекс Музыки через [[download-system]].

## Главный результат версии

MusicArk умеет создавать [[download-task]] для треков Яндекс Музыки, скачивать файлы, сохранять их в [[local-archive]] и создавать [[local-audio-file]].

## Входит

- [[yandex-music-download-provider]];
- создание задач скачивания для [[track-source]] типа yandex_music;
- скачивание одного трека;
- пакетное скачивание;
- выбор качества;
- обработка ошибок;
- retry;
- сохранение файла в [[local-archive]];
- создание [[local-audio-file]];
- связь ProviderTrack -> [[track-source]] -> [[download-task]] -> [[local-audio-file]];
- запись результата в [[history-audit-log]].

## Не входит

- torrent;
- upload в Яндекс Музыку;
- полноценный UI;
- автоматическая синхронизация;
- идеальный matcher.

## Критерии готовности

- можно скачать один выбранный трек;
- можно скачать набор треков;
- файл сохраняется в понятную структуру;
- после скачивания создаётся [[local-audio-file]];
- повторное скачивание не создаёт лишние дубли без необходимости;
- ошибки видны в журнале;
- задача загрузки имеет корректный статус.

## Возможные CLI-команды

```text
musicark yandex download-track --id ...
musicark yandex download-likes --limit 10
musicark download queue
```

## Риски

- скачивание может быть нестабильным из-за неофициального API;
- часть треков может быть недоступна;
- могут быть ограничения по качеству;
- массовые операции могут вызвать лимиты;
- структура файлов может быстро стать мусорной.

## Решение

Скачивать через [[download-system]], а не напрямую из [[yandex-music-provider]].

Иначе [[torrent-download-provider]] потом будет чувствовать себя как гость, которому забыли поставить стул.
