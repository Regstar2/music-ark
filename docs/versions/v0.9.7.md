# MusicArk v0.9.7 — Settings, Help & About UI Polish

## Цель

v0.9.7 завершает v0.9.x desktop UI polish переработкой utility-разделов `Настройки`, `Помощь` и `О приложении`. Версия улучшает информационную иерархию, плотность desktop-компоновки и локальную справку без изменения музыкальной бизнес-логики.

## Baseline

Версия строится поверх принятого в `main` v0.9.6 (`Sync Page UI Polish`). Существующие границы Local Library, Matching, Variant, Coverage, Downloads, Controlled Sync, Metadata Editor, provider authentication и playback остаются авторитетными.

## Settings redesign

Settings использует центральную область с максимальной шириной около `1180 px` вместо растягивания utility-контента на всю ширину окна.

Экран включает:

- header с описанием и компактным индикатором автоматического сохранения;
- responsive карточку темы `System / Light / Dark`;
- responsive карточку языка `System / Russian / English`;
- provider/account card на существующем `AccountSessionController`;
- fallback-аватар с инициалами или generic user icon без выдуманного Yandex avatar URL;
- отдельную секцию `Справка и информация` с переходами в Help и About.

Прежняя отдельная карточка `Общие`, содержавшая только пояснение об автосохранении, удалена. Theme/locale продолжают применяться сразу и сохраняться существующим typed settings store.

## Help redesign

Help остаётся полностью локальной/offline справкой и теперь сгруппирован в четыре блока:

```text
Библиотека
  → Яндекс Музыка
  → Локальная библиотека

Анализ коллекции
  → Сопоставление
  → Версии треков и цензура
  → Недостающие

Восстановление и действия
  → Загрузки
  → Синхронизация
  → Редактор метаданных

Приложение
  → Обложки и воспроизведение
  → Настройки
  → Безопасность данных
```

Каждая тема имеет короткое описание в закрытом состоянии и подробное объяснение после раскрытия. Справка явно фиксирует различия:

```text
Identity != Metadata
Identity != Variant
Similarity != confirmed identity
Missing != Different Version
Apply Metadata != Apply + Bind
```

Также описаны ORIGINAL/CENSORED labels, Variant acceptance, Download task states, Controlled Sync safety model, MP3/ID3 write boundary, artwork priority и private playback cache.

## About redesign

About получает полноценную desktop-компоновку:

- product card с существующим векторным `MusicArkMark` и версией;
- section `Версия и среда` с responsive two-column/one-column layout;
- безопасную diagnostics action;
- стандартный Flutter license UI;
- GitHub repository section.

Новая внешняя dependency не добавляется. Поскольку проект ранее не содержал подтверждённого external-URL launcher, GitHub action использует честный `Copy GitHub link` fallback вместо неработающей кнопки открытия браузера.

Diagnostic clipboard остаётся ограничен версией приложения/backend/schema, OS, theme и locale. Tokens, cookies, protected URLs, library paths/list/content в него не добавляются.

## Utility navigation

Help и About остаются внутри текущего shell `IndexedStack`. Обе страницы получают явный breadcrumb/back action в Settings без нового routing framework.

Возврат не пересоздаёт Yandex workspace, account session или application-wide Now Playing.

## Responsive desktop behavior

Общие utility layout tokens расширены:

- max utility content width: `1180 px`;
- preference/account rows reflow below desktop-wide thresholds;
- About environment data переключается с двух колонок на одну;
- Help использует grouped expansion rows без обязательного horizontal scrolling.

Целевые desktop validation sizes остаются согласованы с `ui-design-system.md`: 1920×1080, 1600×900, 1366×768 и окно около 900 px шириной.

## Localization

Все новые пользовательские строки добавлены в существующий generated RU/EN ARB catalog. Provider data, filenames, paths, IDs и backend codes не переводятся.

RU и EN содержат одинаковый набор Help topics и одинаковую смысловую полноту.

## Version / schema

- Python package: `0.9.7`;
- Flutter application: `0.9.7+1`;
- application/backend release version in `AppInfo`: `0.9.7`;
- SQLite schema: `1.8.4` — без изменений.

v0.9.x использует единый package/release version для Python bridge и desktop application; v0.9.7 не изменяет backend domain contracts.

## Automated checks

В source branch добавлены/обновлены Flutter widget regressions для:

- Settings theme/locale/auto-save controls;
- signed-out и signed-in provider card;
- long display-name overflow;
- grouped Help и новых Variant/Safety topics;
- Help/About back navigation;
- About version/diagnostics/licenses/repository actions;
- utility pages при narrow desktop width;
- актуальной версии в существующем shell test.

`flutter analyze`, targeted/full Flutter tests, Python regression suite и GitHub Actions считаются пройденными только после фактического выполнения на финальном PR head.

## Manual Windows acceptance

Перед принятием версии проверить на Windows:

1. Settings на широком и уменьшенном окне;
2. Light / Dark / System themes;
3. Russian / English locales;
4. logged-in и logged-out provider card;
5. все 11 Help topics и раскрытие подробного текста;
6. Help → Settings и About → Settings;
7. About version/environment layout;
8. diagnostics copy;
9. standard dependency licenses;
10. GitHub link copy action;
11. сохранение Now Playing и Yandex session/page state;
12. отсутствие `RenderFlex` overflow.

## Non-goals

v0.9.7 не добавляет и не меняет:

- Matching algorithms/confidence;
- Variant classification;
- Coverage truth;
- Download execution semantics;
- Controlled Sync planner/Apply semantics;
- Metadata Editor write pipeline;
- provider API или credential handling;
- playback engine;
- SQLite schema;
- mobile redesign;
- state-management/routing framework;
- telemetry;
- Yandex Upload или reverse Sync.

## Риски / ограничения

- About копирует GitHub URL вместо запуска браузера, чтобы не вводить новую dependency только ради одной external action;
- Help описывает текущее подтверждённое поведение v0.9.6 baseline и должна обновляться вместе с будущими изменениями соответствующих workflows;
- visual Windows smoke остаётся обязательным перед окончательным принятием, потому что widget tests не заменяют проверку реального desktop rendering.
