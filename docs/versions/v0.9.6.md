# MusicArk v0.9.6 — Sync Page UI Polish

## Цель

v0.9.6 перерабатывает экран `Синхронизация` как desktop-oriented workflow: выбрать область, увидеть фактическое состояние, понять ожидаемое действие, применить безопасный Controlled Sync и при необходимости перейти к разбору блокирующих операций.

Версия не меняет семантику Controlled Sync, DownloadService, Matching, Coverage, Variant Detection, Metadata Editor или SQLite.

## UI

Экран `SyncPage` теперь включает:

- компактный header с локализованным описанием и явным refresh action;
- responsive configuration card для области синхронизации и папки загрузок;
- status/summary card с основным Sync action и переходом в Downloads;
- визуальное текущее и прогнозируемое локальное покрытие;
- пять основных метрик: Yandex, Local, Download, Queued и Needs review;
- единый список операций вместо набора больших `ExpansionTile`;
- локальные counted filters для Download / Decision / Matching / Variant / Local-only;
- desktop table на широкой области и stacked rows на узкой;
- theme-aware placeholder вместо расширения backend только ради artwork;
- tooltip для полного пути папки и refresh control.

Фильтр плана является только presentation state. Его переключение не пересоздаёт backend plan и не изменяет persisted Sync state.

## Локализация

`SyncPage` больше не содержит пользовательских hard-coded русских строк. v0.9.6 переиспользует существующий generated RU/EN `AppLocalizations` catalog через небольшой `SyncLocalizations` presentation adapter. Отдельное хранилище переводов и новая localization dependency не вводятся.

## Controlled Sync — сохранённые границы

Нормальный Apply остаётся enqueue-only и работает через существующий Sync bridge/application boundary.

```text
deleted local files = 0
moved/renamed local files = 0
modified existing local audio/tags = 0
Yandex mutations = 0
automatic Different-Version replacement = 0
```

Подтверждение перед Apply сохранено. Existing local files и Yandex collection не получают новых mutation-paths от v0.9.6.

## Responsive behavior

- wide workspace: configuration controls располагаются рядом, summary actions могут оставаться в одной строке, plan отображается как таблица;
- medium workspace: controls/actions переносятся, metric cards используют Wrap;
- narrow workspace: вертикальная композиция, horizontally scrollable filters и stacked operation rows без обязательного mobile redesign.

Границы определяются через `LayoutBuilder`, а не по конкретной ОС.

## Automated checks

В ветке добавлены/обновлены Flutter widget tests для:

- summary metrics и blocker aggregation;
- current/projected coverage;
- counted local filters;
- сохранения confirmation before Apply;
- no-target disabled state;
- decision action и rebuild plan;
- Matching/Variant routes;
- Downloads shortcut;
- target folder selection;
- narrow desktop layout;
- English localization;
- отсутствия прежних `ExpansionTile` в Sync plan.

Результат `flutter analyze`, targeted/full Flutter tests и Python regression suite должен фиксироваться только после фактического запуска против финального PR head.

## Manual Windows acceptance

Перед принятием версии проверить на Windows:

1. открыть `Синхронизация` на широком окне;
2. проверить configuration, status, coverage, metrics и plan filters;
3. уменьшить окно и убедиться в отсутствии overflow;
4. проверить Light/Dark/System theme;
5. проверить Russian/English locale;
6. сменить scope и убедиться, что backend plan пересчитывается только по существующему workflow;
7. сменить download folder;
8. при наличии Missing+Wanted убедиться, что Apply по-прежнему требует confirmation;
9. проверить переходы в Downloads и Matching;
10. убедиться, что Sync не изменяет существующие local audio files и Yandex collection.

## Ограничения

- v0.9.6 не расширяет Sync payload ради artwork; если operation metadata не содержит обложку, используется локальный theme-aware placeholder;
- реальный timestamp последнего пересчёта не показывается, потому что текущий bridge не предоставляет подтверждённый timestamp для этой UI-семантики;
- Yandex Upload и reverse Sync не реализуются этой версией.
