# v0.4-local-library

## Цель

Научиться сканировать локальную музыкальную библиотеку и регистрировать файлы в MusicArk.

## Главный результат версии

Приложение умеет выбрать папку с музыкой, просканировать аудиофайлы, прочитать базовые метаданные, вычислить хеши и создать [[local-audio-file]].

## Входит

- выбор локальной папки;
- рекурсивное сканирование аудиофайлов;
- создание [[local-audio-file]];
- чтение базовых тегов;
- определение длительности;
- определение формата;
- вычисление sha256;
- сохранение локальных файлов в [[storage]];
- создание локального [[track-source]];
- базовый отчёт по локальной библиотеке;
- запись событий в [[history-audit-log]].

## Не входит

- полноценный редактор метаданных;
- автоматическое сопоставление с Яндекс Музыкой;
- скачивание;
- torrent;
- GUI.

## Критерии готовности

- можно указать папку с музыкой;
- приложение находит аудиофайлы;
- создаются записи [[local-audio-file]];
- хеши считаются стабильно;
- метаданные читаются хотя бы базово;
- повторный скан не создаёт мусорные дубли;
- повреждённые или неподдерживаемые файлы логируются.

## Возможные CLI-команды

```text
musicark local scan --path "D:/Music"
musicark local list
musicark local stats
```

## Риски

- грязные теги;
- одинаковые файлы в разных папках;
- разные версии одного трека;
- неподдерживаемые форматы;
- слишком медленное хеширование большой библиотеки.

## Решение

На этом этапе не пытаться идеально понимать музыку.

Нужно стабильно индексировать файлы. Матчинг будет в [[v0.7-matching]]. И да, отложить сложную проблему — иногда не трусость, а архитектурная гигиена.
