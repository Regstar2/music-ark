# MusicArk README standard

`README.md` is the primary Russian public README and `README_EN.md` is the English counterpart.

Both must use the same factual structure and describe only implemented/current behavior.

Before v1.0 publication verify:

- current version/status and Windows scope;
- installation/portable usage from actual final artifacts;
- required/optional dependencies;
- actual proxy/WARP behavior and limitations;
- update behavior and trust model;
- Bug/Feature feedback path;
- privacy/safety limitations;
- development/test commands that actually exist;
- links to release, documentation and license;
- known limitations and unsupported behavior.

Do not expose `.project-rules/` as user-facing documentation; these are development constraints, not product features.
