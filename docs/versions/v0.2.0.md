# v0.2.0 — Persistent Library

## Цель

Сделать подтверждённый Yandex Likes flow постоянным desktop-сценарием, пригодным для ежедневного запуска.

## User flow

```text
first launch
  -> enter token
  -> authenticate
  -> fetch Liked
  -> save token securely
  -> cache snapshot

next launch
  -> read secure token
  -> show cached snapshot
  -> refresh from Yandex
  -> atomically replace snapshot
```

## Безопасность

Token не хранится в SQLite и не передаётся в command-line arguments. При первом login Flutter передаёт его только через child-process environment. После этого token читается из credential store.

## Error behavior

Неуспешный refresh не заменяет и не очищает последний успешный snapshot. Пользователь может продолжать просматривать cached library. SQLite cache errors включают исходную безопасную диагностическую причину, чтобы различать schema conflict, database lock и constraint failures.
