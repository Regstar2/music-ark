# android-background-risk

## Назначение

Риск ограничений Android для долгих фоновых задач.

## Отвечает за

- учитывать ограничения фоновой работы;
- сохранять прогресс задач;
- делать операции возобновляемыми;
- не переносить тяжёлые desktop-сценарии на Android без адаптации;
