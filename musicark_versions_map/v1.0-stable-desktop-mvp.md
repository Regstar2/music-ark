# v1.0-stable-desktop-mvp

## Цель

Собрать стабильную первую Windows-версию MusicArk.

## Главный результат версии

MusicArk становится usable-приложением для Windows: пользователь может подключить Яндекс Музыку, просканировать коллекцию, создать локальный архив, увидеть изменения и безопасно выполнять базовую синхронизацию.

## Входит

- сканирование Яндекс Музыки;
- сканирование локальной библиотеки;
- скачивание доступных треков;
- универсальная [[download-system]];
- локальная база данных;
- история сканов;
- [[matching-engine]];
- [[canonical-library]];
- [[sync-planner]];
- базовый [[sync-executor]];
- графический [[ui]];
- [[download-queue-ui]];
- логи;
- настройки;
- базовое редактирование метаданных;
- безопасное выполнение операций;
- отчёты.

## Не входит

- полноценная Android-версия;
- полноценная поддержка BitTorrent;
- несколько музыкальных сервисов;
- автоматическая массовая замена без подтверждения;
- публичная база источников треков;
- собственный музыкальный плеер;
- идеальный matcher.

## Критерии готовности

- обычный пользователь может пройти основной сценарий без CLI;
- скан коллекции работает;
- локальный архив создаётся;
- скачивание работает через очередь;
- план синхронизации понятен;
- опасные действия требуют подтверждения;
- логи доступны;
- ошибки не теряются;
- приложение не ломает коллекцию при типичном использовании.

## Основной сценарий v1.0

```text
1. Пользователь запускает MusicArk.
2. Подключает Яндекс Музыку.
3. Запускает скан.
4. Выбирает локальную папку.
5. Скачивает доступные треки.
6. Повторно сканирует коллекцию позже.
7. Видит новые, недоступные и изменённые треки.
8. Подтверждает безопасные операции.
9. Получает журнал действий.
```

## Риски

- слишком много функций для v1.0;
- нестабильность Яндекс API;
- тяжёлый UI;
- ошибки в matching;
- проблемы упаковки приложения.

## Решение

v1.0 должна быть стабильной, а не “всё, что пришло в голову”.

Функции можно добавить позже. Доверие пользователя после порчи коллекции добавить сложнее. Не то чтобы люди это понимали, но мы попробуем.
