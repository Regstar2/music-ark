# Roadmap

Roadmap фиксирует последовательность, а не обещание сроков.

## v0.1.0 — Yandex likes MVP

Один рабочий desktop-сценарий: токен, вход, «Мне нравится».

## После v0.1.0

Следующая версия выбирается только после ручной проверки v0.1.0. Возможные направления:

- безопасное сохранение сессии/токена;
- локальный cache библиотеки;
- автономная Windows-упаковка Python;
- возвращение локальной библиотеки;
- затем — matching/download/sync.

Legacy-функции не возвращаются в UI автоматически только потому, что их код уже существует.
