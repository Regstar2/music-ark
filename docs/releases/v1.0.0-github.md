MusicArk v1.0.0 is the first stable public Windows x64 release.

[Полное описание на русском](../../blob/v1.0.0/docs/releases/v1.0.0.md) ·
[Full release notes in English](../../blob/v1.0.0/docs/releases/v1.0.0_EN.md)

Highlights:

- portable ZIP and per-user Inno Setup installer;
- frozen Python backend runtime and Flutter Windows app included;
- `LICENSE`, `THIRD_PARTY_NOTICES.md` and `licenses/` included in the package;
- stable `update-manifest.json` with installer size and SHA-256;
- signing status: `UNSIGNED`.

Assets:

- `MusicArk-1.0.0-win-x64.zip`
- `MusicArk-Setup-1.0.0-x64.exe`
- `SHA256SUMS.txt`
- `update-manifest.json`

MusicArk uses an unofficial Yandex Music API wrapper. MusicArk is not an
official Yandex product and is not affiliated with Yandex.
