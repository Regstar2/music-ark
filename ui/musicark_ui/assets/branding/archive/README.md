# MusicArk Icon Archive

This folder stores previous MusicArk icon candidates for release review.

Only `../musicark_app_icon.png` is the active Flutter branding asset. Windows
runner and installer icons are generated into
`../../windows/runner/resources/app_icon.ico` from the active image.

Archived candidates are intentionally not listed in `pubspec.yaml`, so they do
not become runtime Flutter assets.

## Files

- `musicark_app_icon_v0_legacy.png` - byte-for-byte previous tracked
  MusicArk app icon; kept for history even though common image tooling may not
  recognize it as a normal PNG.
- `musicark_app_icon_v1_telegram.png` - first 2026-08-27 replacement candidate.
- `musicark_app_icon_v2_traced.svg` - SVG trace candidate kept as source art.
