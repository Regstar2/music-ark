# future-torrent-support

## Цель

Добавить BitTorrent как дополнительный [[download-provider]] для легального пополнения локальной музыкальной библиотеки.

## Статус

Будущая функция.

На ранних версиях torrent не реализуется, но архитектура [[download-system]] должна быть готова к его добавлению.

## Главный результат будущей версии

MusicArk сможет принимать пользовательские `.torrent` файлы и magnet-ссылки, скачивать выбранные аудиофайлы и добавлять результат в [[local-archive]] как [[local-audio-file]].

## Входит

- импорт `.torrent` файлов;
- импорт magnet-ссылок;
- [[torrent-download-provider]];
- создание [[download-task]] типа torrent;
- показ torrent-задач в [[download-queue-ui]];
- выбор файлов внутри раздачи;
- фильтрация аудиофайлов;
- скачивание выбранных файлов;
- создание [[local-audio-file]];
- передача результата в [[matching-engine]];
- ручная проверка через [[conflict-resolver]];
- запись событий в [[history-audit-log]].

## Не входит

- публичная база torrent/magnet-ссылок;
- автоматический поиск коммерческих треков;
- встроенный каталог пиратских источников;
- автоматическое скачивание без пользовательского импорта;
- привязка torrent к Яндекс Музыке.

## Критерии готовности

- пользователь может добавить `.torrent`;
- пользователь может добавить magnet-ссылку;
- приложение показывает файлы внутри раздачи;
- пользователь выбирает, что скачивать;
- после завершения создаётся [[local-audio-file]];
- файл попадает в [[local-archive]];
- результат можно сопоставить с [[track]];
- спорные случаи уходят в [[conflict-resolver]];
- нет встроенного каталога ссылок.

## Риски

- юридическое неправильное позиционирование;
- ожидания пользователей “искать всё автоматически”;
- сложность torrent engine;
- много мусорных файлов внутри раздач;
- плохие метаданные скачанных файлов;
- размер и стабильность мобильной реализации.

## Решение

Torrent — это download backend, а не музыкальный сервис и не каталог.

Пользователь сам добавляет источник. MusicArk только скачивает выбранные файлы, индексирует их и связывает с локальной коллекцией. И да, даже это надо будет объяснить явно, потому что интернет любит превращать любую функцию в цирк с нарушениями.
