# Project naming

New repository names use lowercase kebab-case by default. Existing repositories are not renamed only for style consistency.

MusicArk keeps:

```text
Repository: music-ark
Product: MusicArk
Python package: musicark
Flutter package/application identifiers: platform-specific existing values
```

Do not rename repository, package, application ID, namespace or public product automatically as part of v1.0 release hardening.
