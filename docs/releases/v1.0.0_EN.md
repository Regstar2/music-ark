## About this release

v1.0.0 is the first stable public MusicArk release for Windows x64. It freezes
the existing desktop MVP without adding new product scope during release freeze:
local library, Yandex Music integration, Matching, Coverage, Downloads, Metadata
Editor, Controlled Sync, feedback and verifiable Windows distribution.

MusicArk's own code is distributed under the MIT License. Third-party
components keep their own licenses; see `THIRD_PARTY_NOTICES.md` and
`licenses/`.

MusicArk uses an unofficial Yandex Music API through a third-party library.
MusicArk is not an official Yandex product and is not affiliated with Yandex.

## Highlights

- The first stable Windows x64 release pipeline publishes a portable ZIP,
  per-user installer, `SHA256SUMS.txt` and `update-manifest.json`.
- Portable and installed builds include the Flutter desktop app and frozen
  Python backend runtime; users do not need a developer checkout or system
  Python installation.
- The release package includes `LICENSE`, `THIRD_PARTY_NOTICES.md` and
  `licenses/`.
- The update flow checks the manifest, installer size and SHA-256 before launch
  and requires explicit user confirmation.
- Signing status: `UNSIGNED`. No suitable code-signing certificate with a
  private key was found in the checked environment.

## Installation and updating

### New installation

Download one of the files from GitHub Release:

- `MusicArk-Setup-1.0.0-x64.exe` - normal per-user installation into
  `%LOCALAPPDATA%\Programs\Music Ark`;
- `MusicArk-1.0.0-win-x64.zip` - portable package; extract the ZIP and run
  `Music Ark.exe`.

Windows may show a SmartScreen warning because v1.0.0 is published without an
Authenticode signature.

### Updating

MusicArk stores user data separately from the installation directory:
`%LOCALAPPDATA%\MusicArk`. Ordinary uninstall does not remove the user's
database, caches or settings.

The stable updater uses:

```text
https://github.com/Regstar2/music-ark/releases/latest/download/update-manifest.json
```

Update flow:

```text
check   -> read and validate manifest
prepare -> download installer and verify size + SHA-256
apply   -> re-verify and launch installer after confirmation
```

Updating from an earlier public stable version was not tested because v1.0.0 is
the first public stable release.

## Known issues

- v1.0.0 artifacts are published as `UNSIGNED`; Windows SmartScreen may warn on
  first installer or executable launch.
- Windows x64 is the only release platform.
- Full safe metadata writing is implemented for MP3/ID3. Other formats remain
  read-only in Metadata Editor unless a dedicated safe writer exists.
- Provider functionality depends on external APIs and Yandex Music availability.
- MusicArk is not a bidirectional filesystem mirror and must not automatically
  delete, rename or overwrite local tracks.
