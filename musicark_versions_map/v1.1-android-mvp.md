# v1.1-android-mvp

## Цель

Перенести основные функции MusicArk на Android.

## Главный результат версии

Появляется Android-версия, которая использует тот же Python Core, но с платформенным bridge и ограниченным набором тяжёлых операций.

## Входит

- Flutter Android UI;
- Android-реализация [[platform-bridge]];
- подключение Python Core;
- работа с токеном;
- сканирование коллекции Яндекс Музыки;
- просмотр состояния коллекции;
- базовая очередь загрузок;
- базовое скачивание;
- доступ к локальному хранилищу;
- настройки;
- отображение логов;
- учёт ограничений фоновой работы.

## Не входит

- полный parity с Windows;
- тяжёлые массовые операции без ограничений;
- полноценный torrent;
- поддержка нескольких сервисов;
- сложный редактор метаданных, если это неудобно на мобильном;
- фоновая магия, которая “точно будет работать”, потому что Android так не живёт.

## Критерии готовности

- приложение запускается на Android;
- UI вызывает Python Core;
- можно проверить авторизацию;
- можно сканировать коллекцию;
- можно просматривать проблемные треки;
- можно запускать ограниченное скачивание;
- ошибки отображаются;
- состояние задач сохраняется;
- приложение не делает вид, что Android не убивает фоновые процессы.

## Риски

- встроенный Python на Android;
- размер приложения;
- ограничения фоновой работы;
- доступ к файлам;
- энергопотребление;
- различия с Windows-версией.

## Решение

Android MVP должен быть осторожным.

Сначала просмотр, сканирование и базовое скачивание. Тяжёлую синхронизацию лучше оставить Windows-версии, пока мобильная часть не станет достаточно стабильной.
