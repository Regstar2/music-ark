FFmpeg binary source information for MusicArk v1.0.0
====================================================

MusicArk v1.0.0 redistributes this FFmpeg executable through the
imageio-ffmpeg 0.6.0 Windows wheel:

  .venv/Scripts/_internal/imageio_ffmpeg/binaries/ffmpeg-win-x86_64-v7.1.exe

The redistributed executable reports:

  ffmpeg version 7.1-essentials_build-www.gyan.dev
  configuration includes --enable-gpl --enable-version3

MusicArk does not modify FFmpeg. The executable is treated as GPLv3 for
distribution notices because its own runtime configuration enables GPL and
version-3 components.

Upstream/source locations checked for this release:

  https://ffmpeg.org/
  https://ffmpeg.org/download.html
  https://github.com/FFmpeg/FFmpeg
  https://www.gyan.dev/ffmpeg/builds/

The GNU GPL v3 text is included at:

  licenses/GPL-3.0.txt

If the upstream build/source links become unavailable, open an issue at:

  https://github.com/Regstar2/music-ark/issues

and request the corresponding source information for the FFmpeg binary
redistributed with MusicArk v1.0.0.
