# ui

## Назначение

Пользовательский интерфейс MusicArk.

## Отвечает за

- показывать состояние коллекции;
- показывать источники треков и локальные файлы;
- показывать [[download-queue-ui]];
- показывать планы синхронизации;
- показывать конфликты;
- показывать логи и настройки;
- передавать команды в [[core]] через [[platform-bridge]];

## Связи

- [[ui]] -> [[core]]
- [[ui]] -> [[sync-planner]]
- [[ui]] -> [[sync-executor]]
- [[ui]] -> [[download-system]]
- [[ui]] -> [[metadata-engine]]
- [[ui]] -> [[storage]]
- [[ui]] -> [[platform-bridge]]
- [[ui]] -> [[provider-capabilities]]
- [[ui]] -> [[download-queue-ui]]
- [[ui]] -> [[conflict-resolver]]

## Правила

UI не должен сам решать, что скачивать, удалять или заменять. Кнопка не должна думать. Это её главное достоинство.
