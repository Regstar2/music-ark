# metadata-chaos-risk

## Назначение

Риск грязных и несовпадающих метаданных.

## Отвечает за

- учитывать разные версии названий;
- учитывать разные записи исполнителей;
- не доверять одному только названию файла;
- использовать ручную проверку спорных случаев;
