# v0.8 — Controlled Sync

## Цель

Добавить безопасный управляющий слой над уже работающими Yandex Library → Local Library → Matching → Coverage → Download слоями.

## Production contract

```text
Yandex active scope = desired
Coverage / Local Library = actual
        ↓
read-only planner
        ↓
immutable preview
        ↓
staleness check + confirmation
        ↓
execution-time revalidation
        ↓
DownloadService.enqueue() for Missing + Wanted only
```

Scopes: all / liked / one active Yandex Playlist. Identity is `(provider_id, external_id)` and is deduplicated across collection memberships/playlist duplicate occurrences.

Production operations: `ENQUEUE_DOWNLOAD`, `REVIEW_IDENTITY`, `REVIEW_VARIANT`, `USER_DECISION_REQUIRED`, `LOCAL_ONLY`.

Legacy upload/replace/metadata operation values remain readable but are unsupported by v0.8 Apply. Apply never deletes/moves/renames local music, edits tags, mutates Yandex, or drains the global Downloads queue.

## Done when

User can create a local/offline dry-run plan, inspect safe downloads and blockers, see stale state, explicitly confirm Apply, enqueue only still-current Missing+Wanted tasks through v0.7 `DownloadService`, open Downloads, rebuild after completion, and observe the diff shrink.

See `docs/versions/v0.8.0.md` for the authoritative current specification. Next major product scope: TBD / stabilization.
