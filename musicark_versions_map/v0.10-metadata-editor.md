# v0.10-metadata-editor

## Цель

Добавить редактирование метаданных локальных аудиофайлов.

## Главный результат версии

Пользователь может смотреть и исправлять метаданные локальных файлов внутри MusicArk.

## Входит

- экран Metadata Editor;
- просмотр тегов [[local-audio-file]];
- изменение названия;
- изменение исполнителя;
- изменение альбома;
- изменение номера трека;
- изменение года;
- изменение жанра;
- работа с обложкой;
- сохранение изменений в файл;
- обновление [[storage]];
- запись изменений в [[history-audit-log]];
- базовые массовые операции.

## Не входит

- сложные правила автонормализации;
- полноценный tagger уровня MusicBrainz Picard;
- автоматическая правка всей библиотеки без подтверждения;
- audio fingerprinting, если он ещё не реализован.

## Критерии готовности

- пользователь видит текущие теги;
- пользователь может изменить базовые поля;
- изменения записываются в файл;
- база обновляется после изменения;
- действие попадает в журнал;
- ошибка записи не ломает файл молча;
- можно откатить хотя бы через историю/резервную копию или ручное восстановление.

## Риски

- повреждение тегов;
- несовместимость форматов;
- потеря обложек;
- массовое неправильное изменение;
- ухудшение matching после правок.

## Решение

Любая массовая правка должна проходить через подтверждение и журнал.

Метаданные — это вроде бы просто текст, пока не потеряешь 2000 обложек и не начнёшь смотреть на жизнь иначе.
