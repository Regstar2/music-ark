# v0.1.0 — Yandex likes MVP

## Цель

Получить воспроизводимый Windows desktop flow: запуск приложения, ввод токена, проверка аккаунта, отображение «Мне нравится».

## Включённые функции

- token form;
- login;
- liked tracks;
- refresh;
- logout;
- MVP process bridge;
- runtime discovery;
- unit/widget tests;
- README run/build instructions.

## Исключённые функции

- downloads;
- sync;
- metadata editing;
- local library UI;
- token persistence;
- installer.

## Затрагиваемые модули

- `src/musicark/mvp_bridge.py`;
- `ui/musicark_ui/lib/`;
- MVP tests;
- project documentation.

## Архитектурные ограничения

- существующий `YandexMusicProvider` переиспользуется;
- token не передаётся через argv;
- MVP list не зависит от SQLite;
- legacy code не удаляется этой версией.

## Автоматические проверки

```powershell
python -m unittest discover -s tests -p "test_*.py" -v
cd ui\musicark_ui
flutter analyze
flutter test
```

## Ручной сценарий

См. `docs/testing/manual-test-plan.md`.

## Критерии готовности

- приложение запускается на Windows;
- валидный токен показывает правильный аккаунт;
- список «Мне нравится» содержит реальные треки пользователя;
- refresh работает;
- logout возвращает форму входа;
- build/test commands в README соответствуют фактической структуре проекта.

## Риски

Реальная интеграция зависит от внешнего сервиса и неофициальной библиотеки. Автоматические тесты не заменяют ручной сетевой прогон.
