# MusicArk README review checklist

Before public v1.0:

- [ ] README.md and README_EN.md have matching facts and section order.
- [ ] Current version/release status is accurate.
- [ ] Installation commands/links point to actual published artifacts.
- [ ] Portable and installer behavior is not described as verified before manual acceptance.
- [ ] Implemented features are separated from roadmap items.
- [ ] Proxy/WARP/update/feedback behavior matches current code.
- [ ] Known limitations are explicit.
- [ ] Build/test badges, if present, point to real workflows.
- [ ] No secrets, private URLs, local paths or user-library data appear.
- [ ] License/release/documentation links work after publication.
- [ ] Wording is direct and factual rather than promotional.
